# CO544 Data Mining and Machine Learning Labs

This repository contains the lab exercises and supporting data files for the CO544 Data Mining and Machine Learning course.

## Repository Structure

- `Lab 01 - Python Data Science Toolbox/`
  - Python notebook for working with data science helper functions and libraries.
- `Lab 02 - Gaussian Distributions & Covariance/`
  - Python notebook focused on Gaussian distributions, covariance, and statistical analysis.
- `Lab 03 - Decision Trees and k-Nearest Neighbors Classification/`
  - Python notebook for decision tree and k-NN classification experiments.
  - Includes `diabetes.csv`, `wine.csv`, and a lab report markdown file.
- `Lab 04 - Clustering and Association Rule Learning/`
  - Notebook exploring clustering and association rule mining.
  - Contains a subfolder with an alternate copy of the lab notebook and dataset.
- `Lab 05 - Text Classification and Performance Analysis/`
  - Text classification lab with movie review data.
  - Includes `movie_reviews/` data set for sentiment analysis.

## Notes

- Open the Jupyter notebooks in each lab folder to run the exercises interactively.
- Data files for each lab are stored alongside the corresponding notebooks.
- The folder names reflect the lab topics and should be used as a guide when navigating the coursework.
